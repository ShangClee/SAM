SAM — Command Line Usage

Usage:

sam [options] Word1 Word2 ...

Options

  • -phonetic — enters phonetic mode
  • -pitch N — set pitch (default 64)
  • -speed N — set speed (default 72)
  • -mouth N — set mouth (default 128)
  • -throat N — set throat (default 128)
  • -wav filename — output to WAV file instead of audio device
  • -sing — special treatment of pitch (sing mode)
  • -debug — enable debug output
  • -buffer-seconds N — set audio buffer size in seconds (default 10)
  • -buffer-bytes N[K|M] — set audio buffer size in bytes, optional K/M suffix

Examples

  ./sam I am Sam
  ./sam -wav out.wav Hello world
  ./sam -buffer-bytes 4K -wav out.wav "Short test"
