Buffer sizing and errors

Buffer allocation is controlled by buffer_seconds (default 10) or by buffer_bytes when explicitly set. The code uses calloc for allocation and reports failures via GetSamError() with codes in src/sam.h.

Integration tests

Integration script: script/test_integration.sh. It:

  • Generates WAV files from sample phrases
  • Verifies WAV headers (mono, 22050Hz)
  • Compares produced WAVs to golden WAVs with tolerance checks (RMS & max diff)

CI

Workflow: .github/workflows/integration.yml. Runs on Ubuntu and macOS and uploads tmp_test_wavs as artifacts.
