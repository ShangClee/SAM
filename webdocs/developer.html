Buffer sizing and errors

Buffer allocation is controlled by buffer_seconds (default 10) or by buffer_bytes when explicitly set. The code uses calloc for allocation and reports failures via GetSamError() with codes in src/sam.h.

Integration tests

Integration script: script/test_integration.sh. It:

  • Generates WAV files from sample phrases
  • Verifies WAV headers (mono, 22050Hz)
  • Compares produced WAVs to golden WAVs with tolerance checks (RMS & max diff)

Web / WASM build

Build script: build_web.sh (needs Emscripten's emcc on PATH).

  • Produces web/sam.js (ES6 module) + web/sam.wasm
  • Runs in browsers and Node (ENVIRONMENT=web,node)
  • UI: web/index.html — text/phonetic modes, voice presets, sing mode, WAV download

WASM API (defined in src/web_wrapper.c):

int sam_web_synthesize(const char *text, int phonetic,
                       int pitch, int speed, int mouth, int throat, int singmode);
char* sam_web_get_buffer(void);
int sam_web_get_sample_count(void);
int sam_web_get_sample_rate(void);
const char* sam_web_get_phonetic_output(void);
int sam_web_get_error(void);          // 0=OK, 1=OOM, 2=PARSE, 3=UNKNOWN
int sam_web_get_error_position(void); // index of the offending input char (PARSE)

Smoke test: node script/test_web_smoke.mjs — imports the shipped artifact, synthesizes in text/phonetic/sing modes, and asserts parse-error reporting.
