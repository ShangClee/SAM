⚡ Quick Start — Typing Phonetic Input

Each phoneme is a 1- or 2-character code
e.g. /H = H sound, EY = "day"
Type the code directly in the SAM web app
Toggle Phonetic input checkbox, then type: /HEHLOW
Add stress with digits 1–8
/HEY2 = "hey" with stress level 2

Show as — in the table. They are unused or internal variants.
